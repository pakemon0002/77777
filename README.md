# PERSONAL HQ

A responsive personal goals and planning dashboard. Open `index.html` in a browser or publish the folder with GitHub Pages.

## Features
- Goal-first dashboard with progress cards and daily task overview
- Four visual themes: Light, Dark, Midnight and Sage
- Subtle motion, responsive layout and modern controls
- Rotating motivational messages
- Task reminders using browser notifications (permission required)
- Local browser storage, JSON import/export

## Reminder note
Browser notifications work while the app is open in a supported browser and notification permission is granted. A static GitHub Pages site cannot reliably deliver scheduled notifications after the browser has fully closed; installable PWA/service-worker push support would require a separate push backend for that behavior.

## Publish
Upload the `personal-hq` folder to a GitHub repository and enable **Settings → Pages** with the branch and root folder selected.
